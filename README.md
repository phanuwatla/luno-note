# Luno Note

A modern, fast, and feature-rich note-taking application designed for productivity.

## Features
- 📝 Clean & intuitive markdown / rich-text editor
- 📂 Flexible workspace, folder & tagging system
- ⭐ Favorites & Quick Navigation
- 🖼️ Seamless local & cloud attachments
- 🎨 Customizable themes and typography
- 💻 Desktop (Electron / Tauri) & Web Support

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Electron Dev
npm run electron:dev

# Tauri Dev
npm run tauri:dev

# Build for production
npm run build
```
